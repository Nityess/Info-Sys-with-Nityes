      Remember this

      Cloud computingThe provision of computer system services by a third party, accessed by the user through the internet. Typical services include data storage, software as a service (SaaS), and infrastructure as a service.
      Cloud accountingAn application of cloud computing where accountancy software is provided in the cloud by a service provider.
      No powerful PCs

      The software runs in the cloud, so an ordinary computer with internet is enough.

      Many users at once

      More than one person can use the software at the same time, from anywhere.

      Reliance on the provider

      The user keeps no local backups, so it depends fully on the provider's security and backups.

      Needs the internet

      No connection, no accounts. Plan for supplier failure too.
