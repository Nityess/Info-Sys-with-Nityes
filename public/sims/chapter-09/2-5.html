Remember this

BlockchainA process used in many distributed ledger systems to ensure that only valid transactions are recorded.
StepWhat happens
1A member records a new block (transaction) onto the ledger.
2The block must be validated by an agreed number of other members.
3Validation means checking a mathematical code on the block, the hash, which is based on the data in the transaction.
4Other members check the hash is correct for the data in the block.
5Once enough members validate, the block is accepted.
6Each block's opening hash equals the closing hash of the block before it.
7Changing a recorded block changes its closing hash and breaks the chain, so it is very hard to change.
